Booth's Multiplication Challenge & Algorithm Flow

Act as the ALU: evaluate bit pairs (Q0, Q-1) and execute the correct operation

📖 How Booth's Algorithm Works (Click to toggle explanation)

▼

Booth's Algorithm is a hardware multiplication technique for 2's complement signed binary numbers. It reduces arithmetic steps by treating strings of 1s in the multiplier as a single addition and subtraction.

  • Bit Pair (Q0, Q-1) = 1 0: Subtract M from AC (AC = AC - M), then Arithmetic Right Shift [AC, Q, Q-1].
  • Bit Pair (Q0, Q-1) = 0 1: Add M to AC (AC = AC + M), then Arithmetic Right Shift [AC, Q, Q-1].
  • Bit Pair (Q0, Q-1) = 0 0 or 1 1: No arithmetic operation. Only perform Arithmetic Right Shift.

Guide the ALU through Restoring Division cycles step-by-step

📖 How Restoring Division Works (Click to toggle explanation)

▼

Restoring Integer Division divides an unsigned dividend $Q$ by divisor $M$. In each iteration $N$ (where $N$ is bit width):

  1. Shift Left: Combined registers [AC, Q] shift 1 bit left.
  2. Subtract Divisor: Compute AC = AC - M.
  3. Test Sign of AC:
      • If AC < 0: Restore previous AC value (AC = AC + M) and set quotient bit Q0 = 0.
      • If AC ≥ 0: Retain subtracted AC value and set quotient bit Q0 = 1.
